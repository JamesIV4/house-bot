## Direct blocker found and fixed

The first processing attempt reached the end of the recording but failed on an
OpenCV random seek near frame 1,534. Upstream seeks independently for every
sampled MP4 frame, which is unreliable on this variable-rate recording.

`patches/mast3r-slam/video-input.patch` changes MP4 input to decode forward
sequentially, corrects timestamps when subsampling, and retains optional
RealSense loading. A standalone decoder pass read all 796 sampled positions,
including final target frame 1,590, before the successful rerun.
